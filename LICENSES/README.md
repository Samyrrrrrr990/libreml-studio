# Third-party license notices

This directory records license texts and notices for material not governed solely by the repository's primary `AGPL-3.0-or-later` license.

Before a release, generate and manually review dependency/license inventories for Python, JavaScript, bundled fonts, icons, datasets, model files, and other assets. An automated inventory is evidence, not a legal conclusion. Do not add third-party code or assets without preserving their required notices and confirming distribution compatibility.

`COMMERCIAL-LICENSE-NOTICE.md` explains the separate commercial-licensing path; it does not grant a license.
